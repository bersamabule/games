# Drill Games

The website for the Drill games: Drill, Drill 2, Drill 3 and Drill Full Version.
Each game is a small installable app (a PWA) that works offline. Host this folder with GitHub Pages.

This folder is generated by `tools/drill-apps/make-site.js`. Do not edit the files by hand: rebuild instead.

Fonts (Saira Stencil One and Barlow Condensed) are under the SIL Open Font License; see `fonts/OFL-*.txt`.
